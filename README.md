# 📊 Tableau Superstore Interactive Dashboard
This project showcases an interactive Tableau dashboard built using the Superstore dataset to analyze **Sales, Profit, and Quantity** across multiple business dimensions.

## 🎯 Objective
To enable dynamic and intuitive analysis of business performance across:
- States
- Categories and Sub-Categories
- Customer Segments
- Shipping Modes
  
## ❗ Business Problem
Business stakeholders needed a clear and interactive way to monitor performance and quickly identify:
- High and low performing segments
- Trends over time
- Key drivers impacting overall performance

Static reports limited exploratory analysis, making it difficult to derive actionable insights efficiently.

## ⭐ Key Features
- Dynamic metric selector (Sales / Profit / Quantity)
- State-wise performance comparison
- Category and Sub-Category profitability analysis
- Segment-level insights
- Ship mode impact on profitability
- Time-based trend analysis
  
## 🛠 Tools & Skills Used
- **Tableau Public** – Data visualization & dashboarding
- **Data Cleaning** – Performed prior to visualization
- **Business Analysis** – Insight-driven dashboard design
